AWS — the working folder

Everything AWS lives here and nowhere else. Start with Book 00; it is self-contained and it is the fastest route to holding an AWS architecture conversation. The rest is depth underneath it.

How files work in here. Filenames are fixed and never change. When a book is updated it is overwritten in place — there is never a second copy with a suffix, and never a date in a filename. If you have a link or a bookmark, it keeps working.

How these are written

One idea per sentence. Jargon defined where it appears or in that book's glossary. A worked example after anything dense. A "say this out loud" line wherever there is an answer worth rehearsing. Length is allowed; density is not.

If a sentence is unclear, that is a defect in the writing, not in you. Flag it and it gets fixed — three have been already.
